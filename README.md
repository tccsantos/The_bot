# The_bot

This is a local website made to manage themes my friends and I set monthly for our Discord server. It may look silly (it is) but it is quite helpful, with how it manages themes, making it simple to add, remove, filter according to seasons and special events, and, finally, choose a theme.
The website is not public to anyone to use it, I setted in my home server, I am the only one who has access to it, as it is not supposed to be on the internet, it is only a managing tool.

## Technologies

- Python
- Django
- sqlite

## Features

- An simple and intuitive UI
- A Database to save all possible themes, users and preferences, with support to customization

## The Process

This bot used to be a simple python script along side a few CSV files, but it was hard to manage and maintain, specially with the growing number of themes. It needed a rework and I also wanted to learn Django, so now I have this project.
Even though the project is silly as an idea, it really helped me learn the fundamentals of the framework. 
 
## Running the Project

1. Clone the repository
2. Set it up in your local machine or local server
3. Start using it
